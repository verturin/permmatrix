# Forum Permission Matrix

## Description
Affiche une matrice de permissions par groupe, accessible aux utilisateurs connectés via une page dédiée.

## Installation
1. Télécharge le ZIP depuis GitHub ou phpBB Customise Database.
2. Décompresse-le dans le dossier `ext/verturin/permmatrix` de ton forum.
3. Dans l’ACP → Extensions, active l’extension.
4. Configure si nécessaire via le panneau d’administration.

## Compatibilité
- phpBB >= 3.3.14, < 4.0.0
- PHP >= 7.2
