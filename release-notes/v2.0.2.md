Ready for the phpBB.com Customisation Database. No functional change, no database change.

## Changes
- Passes phpBB's coding standard (CodeSniffer) with no error and no warning, as checked by the official [test framework](https://github.com/phpbb-extensions/test-framework) on every push.
- `composer.json` aligned on the extensions published on phpBB.com (`phpbb/phpbb` only in `soft-require`).
- EPV (Extension Pre-Validator): **PASSED** — 0 fatal, 0 error, 0 warning, 0 notice.

## Upgrading
- **From 2.0.x:** upload the `verturin/` folder of the zip into `ext/`, replacing the files, then purge the cache.
- **From 1.x:** disable the extension, **delete** `ext/verturin/permmatrix/`, upload, **purge the cache**, enable. See [INSTALL.md](https://github.com/verturin/permmatrix/blob/main/INSTALL.md).

## What 2.0 brings
- `ACP` → `Extensions` → `Permission matrix`: one tab per extension that declares permissions, plus phpBB tabs (Forums, Users, Global moderators, Administrators).
- Batch editing with a recap before anything is written; roles handled like phpBB's ACP (convert or update the role).
- Orphan permissions of removed extensions grouped and explained.
- Public pages of 1.x removed: everything happens in the ACP.

**Requirements:** phpBB 3.3.14+, PHP 7.2+ (tested 8.3, compatible 8.4).
